# Definition of Done

기능이 “코드가 작성됨”을 넘어 다음 세션과 사람이 신뢰할 수 있는 상태인지 판단한다.

## 모든 변경 공통

- 요청과 비목표가 명확하다.
- 관련 GDD, Systems, ADR과 충돌하지 않는다.
- 책임과 상태 소유자가 분명하고 불필요한 새 프레임워크가 없다.
- 사용자 변경과 vendor 파일을 침범하지 않는다.
- diff에 무관한 수정이 없다.
- 실행한 검증, 미실행 검증, 위험이 인계에 기록된다.

## Core 규칙

- UnityEngine 참조 없이 컴파일된다.
- 정상, 경계, 실패, 순서 충돌을 다루는 EditMode 테스트가 있다.
- 시간은 주입 가능하고 랜덤은 seed로 재현된다.
- 같은 입력과 초기 상태에서 동일 결과가 나온다.
- 시스템 계약 문서가 실제 동작과 일치한다.

## Unity Runtime/Presentation

- 필수 직렬화 참조가 시작 전에 검증된다.
- Console에 새 error/exception이 없다.
- 관련 PlayMode 테스트 또는 명시적 수동 재생 검증이 있다.
- 논리 상태와 Transform/VFX 상태가 서로 권위를 다투지 않는다.
- 반복 생성/할당과 생명주기 cleanup을 검토했다.

## 콘텐츠/씬/프리팹

- Unity Editor를 통해 안전하게 저장되었다.
- 누락 참조, 중복 ID, 잘못된 격자 메타데이터 검증을 통과한다.
- 대표 화면 또는 플레이 동작을 시각 확인했다.
- Build Settings와 필요한 에셋 포함 여부를 확인했다.

## 입력/WebGL

- Editor와 실제 WebGL 빌드에서 키보드 입력을 확인했다.
- canvas focus 상실/복구, 방향키 페이지 스크롤 방지, 입력 stuck 해제를 확인했다.
- 사용자 상호작용 뒤 오디오 시작을 확인했다.
- 브라우저 Console에 치명 오류가 없고 로딩/압축 헤더가 정상이다.
- 성능 예산의 측정값 또는 아직 미확정인 이유가 기록된다.

## 마일스톤

- Fast, Full, Web 검증 단계가 모두 통과한다.
- 독립 코드 리뷰의 Blocker/Major가 해결되거나 명시적으로 수용되었다.
- 해당 프로토타입 가설의 계측과 플레이테스트가 수행되었다.
- `CurrentState.md`와 다음 작업이 갱신되었다.
