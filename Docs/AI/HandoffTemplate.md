# AI 작업 인계 템플릿

다음 세션이 대화 기록 없이도 이어갈 수 있도록 사실과 증거를 중심으로 작성한다.

```markdown
## 결과
- 완료된 사용자/플레이어 동작

## 변경
- 파일/에셋: 목적

## 결정
- 결정: 이유, 검토한 대안, 관련 ADR

## 검증
- 실행한 명령/테스트: 결과와 수량
- Unity Console/빌드/브라우저 증거

## 미실행 검증
- 항목: 실행하지 못한 이유, 남은 위험

## 알려진 문제와 가정
- 문제/가정: 영향과 조건

## 다음 작업
1. 가장 안전하고 가치 있는 다음 단계
2. 후속 단계

## 시작 링크
- CurrentState
- 관련 Systems/ADR/Test 문서
```

“테스트 완료” 대신 어떤 테스트가 몇 개 통과했는지 적는다. 실패를 숨기지 않고 이번 변경으로 생긴 회귀인지 기준선에 이미 있던 문제인지 구분한다.
