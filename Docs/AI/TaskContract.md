# AI 작업 계약 템플릿

작업 시작 시 전부 문서 파일로 만들 필요는 없다. 범위가 크거나 여러 세션에 걸치면 이 템플릿을 작업 문서에 복사한다.

```markdown
# 작업: 짧은 이름

## 목표
- 플레이어/개발자가 최종적으로 할 수 있어야 하는 것

## 근거
- GDD/Prototype 섹션
- Systems/ADR 링크
- 현재 코드/에셋 진입점

## 범위
- 변경 허용 경로:
- 변경 금지 경로:
- 명시적 비목표:

## 계약과 불변식
- 입력:
- 출력/관찰 가능한 결과:
- 상태 소유자:
- 실패/경계 동작:
- WebGL 제약:

## 완료 조건
- 구현:
- EditMode:
- PlayMode:
- WebGL/브라우저:
- 문서:

## 검증 명령과 증거
- 명령/도구:
- 예상 산출물:
- 기준선:

## 위험과 롤백
- 직렬화/패키지/성능 위험:
- 롤백 단위:
```

## 판단 규칙

- 외부 API, 저장 형식, 아키텍처, 플레이어에게 보이는 결과가 크게 달라지는 미정 사항은 사용자에게 확인한다.
- 그 외에는 기존 문서와 가장 작은 관습적 동작을 사용하고 인계에 가정을 적는다.
- “재미있다”는 완료 조건을 자동 테스트 하나로 대체하지 않는다.
