## 증거 품질

참가자가 이전에 보고한 세 가지 이동 재현 절차를 같은 수정 build에서 직접 다시 확인했다. 키 해제, 빠른 직교 반복과 벽 모서리 전환의 회귀 판정은 명시적 사용자 확인이 있어 신뢰도가 높다. 그 외 네 항목은 플레이 중 느낀 서술형 피드백이며 방별 행동 기록, 폭탄별 설치 근거, 완료 여부와 직후 세부 인터뷰가 없어 재미 가설의 최종 통과 근거로 사용하지 않는다.

## 유지·변경·보류 결정

- `Keep`: frame 연속 이동과 현재 직교 방향 우선 정책. 보고된 세 입력 결함을 다시 수정하지 않는다.
- `Modify first`: 방 전환 뒤에도 직전 활성 폭탄 슬롯을 run 상태에서 복원한다.
- `Modify candidate`: 방문 방·현재 방·확인된 연결만 표시하는 최소 미니맵 수직 슬라이스를 설계한다. 전체 미탐색 지형 공개나 fast travel은 넣지 않는다.
- `Modify candidate`: 현재 Telegraph→Execute→Recovery 규칙을 유지하면서 위치 예측이 가능한 결정론적 보스 이동 패턴을 추가한다.
- `Deferred by participant`: 방 이동 자동 전회복을 대체할 체력 persistence, 회복방 또는 확률 드롭. 여러 변수를 함께 바꾸지 않는다.
- `Insufficient evidence`: 광역·직선 폭탄의 역할 차이, 갑옷 첫 피격 가독성과 독립 쿨타임의 재미는 다음 플레이에서 계속 관찰한다.
