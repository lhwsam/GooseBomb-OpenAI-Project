## 세션 범위와 증거 품질

참가자는 첫 고정 seed 전투방에서 돌진형이 문에 들어가자마자 공격해 당황스럽고, 초록 추격자는 멀리 도망가도 맞는 듯해 사거리가 길게 느껴진다고 보고했다. 영상과 화면 좌표는 없지만 같은 참가자의 직접 조작 직후 관찰이며, 자동 사건 로그와 구현 구조가 각각 두 현상을 독립적으로 뒷받침한다.

로그에서 `room-ready-prototype-combat-pillars` 뒤 19ms에 `charger-telegraph`, 약 1.01초 뒤 `charger-recover-target`과 접촉 피해가 기록됐다. 다른 구간에서는 `chaser-cell` 확정과 `player-contact-damaged`가 같은 millisecond에 기록됐고, 기존 presenter는 그 확정 이동을 0.5초 동안 보간했다. 따라서 “보이는 적보다 가까운 논리 셀이 먼저 피해를 준다”는 해석의 신뢰도는 높다. 수정 뒤 같은 참가자가 직접 플레이하고 두 교정이 잘 동작한다고 확인했다.

## 결정

- `Modify`: 전역 돌진 수치 대신 `Pillars`의 돌진형 저작 spawn을 `(0,1)`에서 `(-1,1)`로 옮긴다. seed-0 회전 뒤 동쪽 입장 축과 어긋나 최소 한 번의 1 cell/s Track 이동 뒤 예고하게 한다.
- `Modify`: 추격자의 논리 점유는 결정론을 위해 이동 시작에 확정하되, 새 인접 접촉은 같은 `StepInterval`의 도착 시각 이후에도 인접한 경우에만 허용한다.
- `Keep`: 접촉의 cardinal 인접, 피해 1, 공유 0.75초 무적과 돌진형의 0.75초 예고·8 cells/s 돌진 수치는 이번 단일 원인 교정에서 유지한다.
- `Do not infer yet`: 수정 후 방이 쉬워졌는지, 추격자 압박이 약해졌는지, 최종 속도와 배치가 재미있는지는 자동 검증으로 판정하지 않는다.

## 수정 후 자동 증거

- 연결 Unity 전체 EditMode `330/330`, PlayMode `133/133`, 콘텐츠 validator와 빌드 전 Console 오류·경고 0이 통과했다. WebGL 빌드 뒤 Console은 오류 0, 기존 MMFeedbacks 선택 연동·TextMeshPro IL2CPP 안내 경고 6건이다.
- 11씬 Development WebGL Chromium smoke `46/46`에서 seed-0 `Pillars` 준비 뒤 첫 돌진형 관련 행동이 Telegraph가 아닌 Track 이동임을 확인했고, 전체 전투·던전 경로와 browser Console/page error 0이 통과했다.
- 가상 표준 Gamepad smoke `14/14`도 Console/page error 0으로 통과했다. 이 결과는 규칙·연결 회귀 증거이며 수정 후 입장 여유와 접촉 거리의 사람 체감 판정을 대신하지 않는다.
