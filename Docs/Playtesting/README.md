## 목적

자동 테스트가 증명할 수 없는 재미·가독성·공정성을 관찰과 인터뷰로 판단한다. 이 폴더는 세션 실행 방법과 사람이 읽을 수 있는 결과 형식을 소유하며 게임 규칙을 재정의하지 않는다.

## 증거와 결과 분리

- 원본 영상, 스크린샷, 브라우저 로그와 개인 식별 가능 정보는 Git에 넣지 않는다.
- 원본 증거는 `Artifacts/Playtests/<session-id>/` 아래에 두고 파일명과 해시 또는 설명만 결과 문서에서 참조한다.
- 유지/변경/제거 결정과 근거가 되는 익명 관찰 요약은 `Docs/Playtesting/Results/`에 별도 문서로 남긴다.
- 자동 probe 사건은 실제 Core 전이 확인 보조다. 행동 의도와 재미를 대신 판정하지 않는다.
- 적은 참가자 수를 성공률로 과해석하지 않고 반복되는 행동·설명·혼란을 중심으로 기록한다.

## 세션 운영 원칙

- 한 세션 도중 규칙이나 수치를 바꾸지 않는다.
- 전략을 유도하는 힌트와 조작 설명을 구분한다.
- 관찰 사실, 참가자 발언, 진행자의 해석을 서로 다른 칸에 기록한다.
- 실패나 사망 직후 원인을 먼저 물어 회상 왜곡을 줄인다.
- 변경은 한 번에 가능한 한 변수 하나만 적용하고 이전 세션의 commit/build를 보존한다.
