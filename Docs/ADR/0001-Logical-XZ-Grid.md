# ADR-0001: 3D 표현과 XZ 논리 격자 분리

- 상태: `Accepted`
- 날짜: 2026-08-14

## 맥락

게임은 3D로 보이지만 폭탄 전파, 벽 차단, 연쇄, 방 구조는 격자 규칙을 요구한다. Transform과 3D Physics를 권위 상태로 사용하면 프레임 순서와 접촉 오차가 규칙 재현성을 해친다.

## 결정

정수 XZ 격자를 셀 점유와 전투 판정의 권위 원본으로 사용한다. Y와 연속 Transform은 표현 계층이 소유한다. 월드↔격자 변환은 Unity 어댑터에서 수행한다.

## 대안

- Physics 중심 판정: 초기 구현은 빠르지만 폭발 차단과 테스트가 불안정하다.
- 2D 프로젝트 전환: 규칙과는 맞지만 요구된 3D 표현을 포기한다.
- NavMesh 중심 공간: 추격에는 유용하나 폭발 셀 규칙의 원본으로 부적합하다.

## 결과

- 규칙 테스트와 seed 재현이 쉬워진다.
- 표현과 논리 위치를 동기화하는 어댑터가 필요하다.
- 연속 이동 감각은 격자 점유 정책과 함께 검증해야 한다.

## 철회 조건

플레이테스트에서 격자 규칙 자체가 폐기될 때만 재검토한다.
