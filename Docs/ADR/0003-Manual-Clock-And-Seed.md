# ADR-0003: 주입 시계와 명시적 seed

- 상태: `Accepted`
- 날짜: 2026-08-14

## 맥락

지연 폭발, 연쇄 지연, 독립 쿨타임, 무적 시간, 절차 생성은 시간과 랜덤 순서에 민감하다. 전역 Unity 시간과 랜덤을 직접 사용하면 테스트와 버그 재현이 어렵다.

## 결정

Core 시간 의존 규칙은 Runtime이 제공한 게임 시간으로 갱신한다. 절차 생성은 명시적 seed를 입력받는다. 정확한 simulation 주기는 첫 수직 슬라이스에서 확정한다.

## 대안

- `Time.time`과 `UnityEngine.Random` 직접 사용: 간단하지만 재현성이 낮다.
- 전체 lockstep 엔진: 현재 싱글플레이 프로토타입에 과하다.

## 결과

- 테스트가 임의 시간 진행과 seed 재생을 사용할 수 있다.
- 시간 정지, 표현 시간, 규칙 시간의 의미를 명확히 해야 한다.
