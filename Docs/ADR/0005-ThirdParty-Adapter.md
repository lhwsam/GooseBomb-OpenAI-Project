# ADR-0005: 서드파티 기능은 어댑터 뒤에서 사용

- 상태: `Accepted`
- 날짜: 2026-08-14

## 맥락

프로젝트에는 Feel, UniTask 등 외부 패키지가 있다. 게임 규칙이 패키지 API에 직접 결합되면 WebGL 호환, 업그레이드, 제거 비용이 커지고 vendor 파일 수정이 발생하기 쉽다.

## 결정

Core는 서드파티를 참조하지 않는다. Runtime/Presentation의 좁은 어댑터에서만 사용하고, vendor 소스는 수정하지 않는다. 패키지 기능이 없어도 규칙 상태는 정상이어야 한다.

## 대안

- 패키지 API 직접 호출: 초기 연결은 빠르지만 결합도가 높다.
- 모든 패키지를 제거: 이미 유용한 표현 도구를 활용하지 못한다.

## 결과

- 연동 파일 수와 책임을 작게 유지해야 한다.
- 패키지 업그레이드 시 어댑터와 WebGL 빌드를 집중 검증한다.
