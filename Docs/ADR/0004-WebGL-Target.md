# ADR-0004: 프로토타입의 1급 빌드 타깃은 WebGL

- 상태: `Accepted`
- 날짜: 2026-08-14

## 맥락

최종 프로토타입은 브라우저에서 즉시 플레이되어야 한다. Editor/Standalone에서만 검증하면 입력 focus, 메인 스레드, 메모리, 압축/호스팅 문제를 늦게 발견한다.

## 결정

WebGL을 기능 완료의 1급 검증 타깃으로 둔다. Core와 입력 어댑터를 분리하고, 브라우저 제한 API를 피하며, 마일스톤마다 실제 WebGL 빌드와 브라우저 스모크 테스트를 실행한다.

## 대안

- 개발 종료 후 WebGL 이식: 플랫폼 위험이 너무 늦게 드러난다.
- Standalone 우선 최적화: 목표 플랫폼과 성능 특성이 다르다.

## 결과

- 단일 스레드 프레임 예산, 메모리, 다운로드 크기를 초기에 관리한다.
- 호스팅 설정도 빌드 산출물 검증의 일부가 된다.
