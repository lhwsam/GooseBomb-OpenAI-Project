# 보스 페이즈 개선안 — 체력 10 기준

- 상태: 규칙 방향과 첫 테스트 범위 `Accepted`, 모든 수치와 재미 판정 `Proposed`
- 기준일: 2026-08-19
- 근거: 기존 체력 4·두 패턴 보스가 쉽고 밋밋하다는 플레이 피드백
- 구현 계약: [보스 전투](../Systems/BossBattle.md)
- 작업 범위와 검증: [보스 페이즈 개편 수직 슬라이스](../Development/BossPhaseReworkSlice.md)

## 핵심 경험

기존의 `폭탄 설치 → 멀리 도망 → 피격 대기`를 다음 흐름으로 바꾼다.

```text
보스·자폭병 관찰
→ 제한 추격을 원하는 방향으로 유도
→ 공격 위치와 fuse를 예측해 폭탄 선행 설치
→ 투척·짝홀 패턴 회피
→ 회피 중에도 준비한 폭탄으로 계속 반격
```

성공한 플레이어는 보스 유도, fuse 계산, 자폭병 역이용, 먼저 폭발한 칸 재사용, 공격 패턴 중 폭탄 적중 중 적어도 하나를 자신의 성공 원인으로 설명할 수 있어야 한다.

## 체력과 전환

| 구간 | 체력 | 역할 |
|---|---:|---|
| 1페이즈 | 10~8 | 기본 유도·돌진·순차 투척·단일 짝홀 학습 |
| 2페이즈 | 7~3 | 자폭병 합동 추격 1회와 강화 투척·짝홀 반전 |
| 최후 발악 | 2~0 | 학습한 규칙의 짧고 강한 조합 |

- 체력 7 이하에서 2페이즈, 체력 2 이하에서 최후 발악을 예약한다.
- 조건 충족 즉시 전환하지 않는다. 현재 시퀀스가 끝난 안전 경계에서 전환한다.
- 연속 피해로 임계값을 넘어도 이미 시작한 전환 연출은 중복 실행하지 않는다.
- 최후 발악은 전투당 한 번만 실행한다. 마지막 과열에 처치하지 못하면 새 자폭병 없이 2페이즈 반복으로 돌아간다.

## 피해 규칙

### 플레이어 폭탄

- 살아 있는 보스는 `Telegraph`, `Execute`, `Recovery`와 현재 패턴 종류에 관계없이 플레이어 폭탄 피해를 받는다.
- 서로 다른 `BombId` 하나당 피해 1을 인정하며 패턴별·과열별 누적 상한은 두지 않는다.
- 같은 폭탄의 동일 폭발과 사망 뒤 폭발만 피해를 주지 않는다.
- 과열은 공격 주기의 휴식·재정비 구간으로 남지만 더 이상 유일한 피해 창이 아니다.

### 자폭병

- 자폭병 폭발이 보스 셀을 포함하면 다른 폭탄과 마찬가지로 피해 1을 준다.
- 같은 자폭병 폭발은 보스에게 한 번만 적용한다.
- 보스 소유 폭탄은 보스에게 피해를 주지 않는다.
- 첫 테스트에서 추가 과열, 공격 취소, 취약 연장 같은 부가 보상은 없다.

## 전체 시퀀스

### 1페이즈

```text
제한 추격 2회
→ 방향 고정 2~3칸 돌진
→ 중앙 복귀
→ 일반 폭탄 3개 순차 투척
→ 한 parity의 행별 순차 파동
→ 과열 1.8~2.2초
```

- 추격은 한 칸이 끝날 때만 플레이어 위치를 다시 읽고 무한히 이어지지 않는다.
- 돌진 방향은 예고 시작 시 고정한다. 예고 후 플레이어를 다시 추적하지 않는다.
- 세 폭탄은 서로 다른 4~6개 후보 앵커를 사용하며 동시에 생성하지 않는다.
- parity 파동은 한쪽 행부터 반대쪽 행까지 진행한다. 먼저 끝난 행은 다음 안전 공간으로 재사용할 수 있어야 한다.

### 2페이즈 전환과 첫 사이클

```text
중앙 복귀
→ 먼 외곽 소환 셀 예고
→ 자폭병 1기 소환
→ 보스 제한 추격 3회 + 자폭병 추격
→ 자폭병 조기 또는 4~5초 강제 점화
→ 자폭병 폭발 해결
→ 중앙 복귀
→ 일반 2 + 연쇄 2 순차 투척
→ 첫 parity 파동 + 반대 parity 파동
→ 과열 1.3~1.7초
```

- 자폭병은 2페이즈 전체에서 한 번만 소환하고 동시에 최대 1기만 존재한다.
- 생성 셀은 플레이어 바로 옆을 피하고, 저작된 외곽 후보 중 플레이어에게서 먼 셀을 우선한다.
- 조기 점화는 기존 접근·플레이어 폭발 규칙을 사용한다. 제한 시간이 끝나면 현재 셀을 고정하고 기존 0.75초 fuse로 강제 점화한다.
- 자폭병이 해결되기 전에 폭탄 4개·짝홀 반전을 시작하지 않는다.
- 보스 최대 추격, 자폭병 최대 추격, 폭탄 4개, 짝홀 반전, 짧은 과열을 동시에 최대 강도로 겹치지 않는다.

### 2페이즈 반복

```text
제한 추격 3회
→ 방향 고정 돌진
→ 중앙 복귀
→ 일반 2 + 연쇄 2 순차 투척
→ 직전과 반대 순서의 parity 반전
→ 과열
```

무작위 선택보다 직전 사이클과 다른 결정론적 순서를 우선한다.

### 최후 발악

```text
짧은 판단 간격의 제한 추격 2회
→ 방향 고정 돌진
→ 중앙 복귀
→ 외곽에서 안쪽으로 연쇄 폭탄 4개
→ parity 반전
→ 마지막 과열 2.0~2.5초
```

새 규칙이나 새 적을 추가하지 않는다. 먼저 폭발한 공간으로 이동하고 두 폭탄으로 남은 체력 2를 끝내는 마지막 시험이어야 한다.

## 이동과 예고

- 정확한 다음 이동 셀 고스트, 추격 도착 셀, 고정 순환 경로의 다음 칸 표시는 제거한다.
- 돌진 범위·차선, 폭탄 착탄 셀, 소환 셀, 짝홀의 현재/첫 파동, 강한 공격 방향은 유지한다.
- 이동은 시작 후 끝날 때까지 방향을 바꾸지 않고 한 칸 종료 시에만 재판단한다.
- 최종 아트에서는 바라보기, 몸 기울임, 발밑 먼지, 짧은 잔상, 돌진 전 지면 긁기, 중앙 장치 발광으로 방향을 전달한다. 현재 프로토타입은 애니메이션·위험 셀·보간으로 최소 가독성을 검증하며 보스 본체의 상태·phase 색 변경은 사용하지 않는다.

## 투척과 논리 점유

```text
준비 → 발사 → 고정 포물선 → 착탄 → 논리 폭탄 설치·fuse 시작 → 폭발
```

- 목표 셀은 투척 시작 전에 확정하고 비행 중 바꾸지 않는다.
- 예고 중 착탄 셀을 예약해 플레이어 폭탄 설치와 중복되지 않게 한다.
- 비행 중에는 논리 폭탄이나 보이지 않는 점유를 만들지 않는다.
- 실제 폭탄은 착탄 순간 기존 `BombSimulation`에 설치하고 그때부터 fuse가 진행된다.
- 포물선은 Rigidbody가 아니라 시작점·착탄점과 경과 시간의 보간이다.
- 일반·연쇄 폭탄은 외형을 구분한다.

## 보스방 조건

- 11×9 논리 arena, 투척 앵커 4~6개, 자폭병 소환 앵커 최소 2개를 저작한다.
- 소환 앵커는 플레이어 시작 셀 바로 옆이 아니어야 한다.
- 합동 추격에서 최소 두 퇴로를 제공하고 자폭 한 번이 모든 퇴로를 동시에 없애지 않는다.
- parity 시작 시 최소 한 회피 경로를 보장한다.
- 특정 플레이어 폭탄 없이도 처치할 수 있고 두 슬롯을 함께 쓰면 더 빨리 끝낼 수 있어야 한다.

## 첫 플레이테스트 범위

포함:

1. 체력 10, 전환 7/2
2. 모든 생존 패턴에서 플레이어 폭탄 피해 허용
3. 정확한 이동 목적지 고스트 제거
4. 1페이즈 추격 2회·돌진·폭탄 3개·단일 parity·과열
5. 2페이즈 전환 시 자폭병 1기·소환 셀 예고·4~5초 강제 점화·보스 피해 1
6. 2페이즈 추격 3회·폭탄 4개·parity 반전·짧은 과열
7. 체력 2 이하 일회성 최후 발악
8. 실제 포물선 투척과 착탄 시 fuse 시작

제외:

- 반복/동시 2기 자폭병
- 보스 체력 회복
- 세 번째 보스 폭탄 종류
- 근접 공격 3종 이상
- 무작위 패턴 선택
- 모든 공격력·속도의 일괄 상향

## 플레이테스트 판정

성공 신호:

- 플레이어가 보스를 원하는 차선으로 유도한다.
- 투척 종료 전에 자신의 폭탄을 설치한다.
- 공격을 피하면서도 폭탄을 계속 적중시키려 시도한다.
- 자폭병을 보스 쪽으로 의도적으로 유도한다.
- 먼저 폭발한 parity 칸을 안전 공간으로 재사용한다.
- 최후 발악을 불공정한 추가 페이즈가 아니라 마지막 시험으로 인식한다.

실패 신호:

- 상시 피해가 가능해져 패턴을 관찰하지 않고 보스 셀에 폭탄만 반복 설치한다.
- 자폭병을 항상 외곽에 버리는 것이 유일한 정답이다.
- 보스와 자폭병 공격이 겹쳐 피격 원인을 설명하지 못한다.
- 폭탄 수만 늘고 새 판단은 생기지 않는다.
- 목적지 고스트 제거 뒤 행동 방향을 읽지 못한다.
- 숙련 플레이도 2분 이상 단조롭게 반복한다.

문제가 생기면 체력보다 동시 공격 수 → 추격 횟수 → 강제 점화 시간/소환 위치 → 투척 간격 → parity 이동 시간 → 상시 적중률과 전투 시간 순서로 조정한다.
