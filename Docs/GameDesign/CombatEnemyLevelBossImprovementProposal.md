# 전투·적 AI·레벨·보스 개선 제안

- 상태: 전체 방향 `Proposed`, 비밀벽 정렬·추격자 BFS·돌진형 차선 획득·장갑병 panic·자폭병/Gates·전용 보스방/실제 보스 폭탄은 구현 계약으로 채택
- 근거: 2026-08-17 프로토타입 플레이 피드백과 현재 코드·WebGL 경로 분석
- 목적: 반복적인 `폭탄 설치 → 외곽 도주 → 대기`를 `관찰 → 선행 설치 → 적·환경 유도 → 퇴로 재계산 → 시간차 회수`로 바꾼다.
- 비범위: 최종 수치, 아트 콘셉트, 성장·아이템·메타 진행 확정

이 문서는 GDD v0.2를 폐기하지 않는다. GDD의 폭탄 유도·두 슬롯·수제 방·보스 가설을 실제 플레이 피드백으로 구체화한 후속 제안이며, 각 항목은 독립 수직 슬라이스의 사람 검증을 통과한 뒤 `Accepted`로 올린다.

## 관찰된 문제

- 일반 전투가 적 근처 설치, 방 외곽 도주, 폭발 대기와 재시도로 수렴한다.
- 추격자와 장갑병은 속도·피격 횟수 외의 공간 질문이 비슷하다.
- 돌진형은 플레이어와 이미 일직선일 때만 공격해 스스로 차선을 만들지 못한다.
- 폭탄은 적에게 강한 점유 벽이지만 적은 이를 위험·상호작용 대상으로 사용하지 않는다.
- 긴 외곽 순환로와 플레이어 5 cells/s 대비 1.75~2.25초 fuse 때문에 설치 후 방 대부분을 횡단할 수 있다.
- 파괴 가능 벽이 전투 중 경로와 적 행동을 충분히 바꾸지 않는다.
- 개선 전 보스방은 일반 추격자용 방을 재사용했고, 공격은 실제 폭탄보다 추상 위험 셀에 가까웠다.
- 보스 Recovery 2.75초가 모든 현재 fuse보다 길어 선행 설치 요구가 약하다.

## 목표 경험

```text
상황 관찰
→ 적의 다음 행동 예측
→ 폭탄 선행 설치
→ 적 또는 환경 유도
→ 퇴로 재계산
→ 시간차 폭발·연쇄
→ 계획 성공 회수
```

플레이어가 성공 원인을 운이 아니라 자신의 배치와 유도로 설명할 수 있어야 한다. 방마다 효율적인 폭탄과 설치 위치는 달라야 하지만, 특정 폭탄이 없으면 클리어할 수 없는 구조는 만들지 않는다.

## 공통 적 계약 후보

- 적은 무시하면 공간·퇴로·타이밍 손해를 주고, 규칙을 읽으면 피할 수 있으며, 미리 설계하면 폭탄·지형과 함께 이용할 수 있어야 한다.
- 강한 행동은 `목표 선택 → 예고 → 목표·방향 고정 → 실행 → 회복` 순서를 따른다. 예고 뒤 플레이어 이동만으로 목표를 바꾸지 않는다.
- 이동 능력과 전투 의도를 분리한다. 경로 탐색은 결정론적 논리 격자를 사용하고 Transform·NavMesh·물리 순서를 권위로 삼지 않는다.
- 매 frame 완전 재탐색하거나 폭발 직전 무작위 회피하지 않는다. 폭탄 위험을 모든 적이 완벽히 알게 하지 않는다.
- 폭탄·적 폭탄·자폭은 가능하면 기존 점유, 벽 차단, 파괴벽, 고정 연쇄 지연과 `BombId` 계열 계약을 재사용한다.

|---:|---|---|---|

## 적별 제안 요약

### 추격자

- 국소 Manhattan을 BFS 거리장으로 교체한다.
- 기존 이동 cadence와 최대 두 칸 방향 유지는 유지하되 최단 경로를 벗어나는 committed step은 중단한다.
- 폭탄 fuse·미래 플레이어 위치를 읽지 않고 폭탄을 이동 장애물로만 본다.

### 돌진형

- 일직선을 제자리에서 기다리지 않고 가장 가까운 유효 정렬 셀로 천천히 이동한다.
- 정렬 뒤 전체 돌진 차선을 예고하고 방향·최대 거리를 고정한다.
- 현재 슬라이스에서 벽·기둥·새 폭탄 충돌은 같은 조기 회복을 사용한다. 폭탄 충돌의 기존 고정 연쇄 지연과 별도 기절은 후속 후보로 남긴다.

### 장갑병

- 장갑 상태는 문·교차점·통로의 제한 반경을 지키는 수비수로 만든다.
- 첫 폭발 뒤 폭발 중심 반대편의 유효 가지와 도착점을 고정·예고하고 약 3셀을 빠르게 이동한다.
- 도착 회복 뒤 살아 있으면 공격 추격으로 전환한다. 단순 1→3 cells/s 추격 반복은 목표가 아니다.

### 자폭병

- 플레이어를 직접 추적하고 가까워지면 본체가 점멸해 위험이 커졌음을 먼저 알린다. 저작 폭발 anchor는 AI 목적지가 아니라 플레이어가 문·벽 주변으로 유도할 때 기대 결과를 검증하는 레벨 저작 정보다.
- 접촉 즉발 대신 인접 상태가 한 판단 cadence 유지되어야 정지·점화하며, 점화 전 플레이어가 벗어나면 다시 추적한다. 점화 뒤에는 짧은 고정 예고와 실제 논리 폭탄을 사용한다.
- 플레이어 폭발에 맞으면 사라지지 않고 고정 지연 뒤 짧은 벽 차단 십자 폭발을 일으켜 플레이어·적·보스·파괴벽에 영향을 주는 후보로 검증한다.

### 퇴로 차단 투척병

- 현재 플레이어 셀 대신 다음 교차점·퇴로 anchor를 예고하고 고정한다.
- 실제 논리 폭탄을 투척해 셀을 점유하고, 플레이어 폭발과 기존 연쇄 문법으로 상호작용한다.
- 방의 2~3개 사격 anchor 사이를 이동하며 같은 자리에서 영구 포격하지 않는다.

## 방 수정 방향

- `Loop`: 초반 추격자+BFS 학습 기준선 유지. 후반 변형만 추가 추격자를 검토한다.
- `Lanes`: 중앙 노출 통로, 교대 엄폐, 투척·퇴로 anchor. 외곽 전체 순환 한쪽을 제한한다.
- `Pillars`: 짧은 돌진 차선 2~3개, 측면 탈출 포켓, 충돌 기둥/파괴벽을 둔다.
- `Armor`: 대칭 순환을 줄이고 Y/T 갈림길과 서로 다른 폭탄 우세 가지를 만든다.
- `Gates`: 자폭으로 열리는 두 비대칭 결과를 제공하고 플레이어 길·적 접근·사격선을 함께 바꾼다.

입장 즉시 피격, 해결 경로 없는 예고, 긴 1셀 폭발 강제 복도, 모든 적에게 영구 안전한 구석과 화면 밖 공격은 허용하지 않는다.

## 보스 재설계 방향

초기 체력 4·`RetreatThrow/CrossChain` 최소 세트는 실제 폭탄·전용 arena 기술 위험을 검증했지만 플레이에서 쉽고 밋밋하다는 피드백을 받았다. 현재 첫 사람 테스트 계약은 [체력 10 보스 페이즈 개선안](BossPhaseImprovementProposal.md)이 대체한다.

- 제한 추격·방향 고정 돌진으로 보스를 원하는 차선에 유도한다.
- 3/4개 실제 폭탄의 착탄·fuse와 행별 parity 파동 중 플레이어 폭탄을 선행 설치한다.
- 과열당 서로 다른 두 폭탄으로 최대 2피해를 주어 두 슬롯 조합 이유를 만든다.
- 2페이즈 전환에서 자폭병 한 기를 보스 쪽으로 역이용할 선택을 제공한다.
- 체력 2 이하에서는 새 규칙 없이 외곽→안쪽 연쇄와 parity 반전을 일회성 최후 발악으로 조합한다.
- 정확한 이동 목적지 고스트는 제거하고 돌진·착탄·소환·첫 parity만 예고한다.

## 검증 질문

- 폭탄 설치 뒤에도 다음 위치를 만들기 위해 계속 움직이는가?
- 방마다 실제 설치 셀과 선택 폭탄이 달라지는가?
- 첫 폭탄이 두 번째 폭탄 위치를 결정하는가?
- 적의 강한 행동은 위험하지만 예고 뒤 해결 가능하고 유도 가능한가?
- 플레이어가 성공·실패 원인을 자신의 배치, 적 유도, 퇴로 선택으로 설명하는가?
- 자동 검증은 결정론·상태 순서·점유·WebGL 회귀를 증명하고, 재미 판정은 고정 빌드 사람 플레이가 맡는다.

## 아직 확정하지 않는 것

- 적별 최종 속도·거리·예고·회복·체력.
- 적 폭탄과 자폭의 정확한 범위·피해·동시 개수.
- 보스 패턴 수, phase 수, 최종 Recovery 길이.
- 신규 적 2종을 모두 프로토타입에 포함할지 여부.
- 아트·오디오·경제·드롭·패시브 아이템과 메타 진행.
